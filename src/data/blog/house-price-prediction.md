## Overview

This project was part of the **Machine Learning Practice** course at IIT Madras. The goal was to build a regression model that accurately predicts house prices based on structured property features.

## Approach

- Analyzed features including location, size, number of rooms, and available amenities
- Applied preprocessing, encoding, and feature engineering pipelines
- Evaluated multiple regression models and selected the best performer based on validation metrics

## Tech Stack

- **Python** — core language
- **Pandas** — data cleaning and feature engineering
- **Scikit-learn** — model training, evaluation, and pipelines
- **Kaggle** — dataset and competition platform
