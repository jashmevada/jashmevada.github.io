## Overview

Quiz Master is a full-stack web application that lets users take quizzes across various topics. It was built with a clean separation between frontend and backend via a REST API.

## Architecture

- **Backend:** Flask REST API handling quiz logic, user state, and data persistence
- **Frontend:** Vue.js with PrimeVue component library for a polished UI
- **Database:** SQLite for storing quiz content and user results
- **Caching:** Redis for session management and performance optimization

## Tech Stack

- **Flask** — Python web framework for the REST API
- **Vue.js + PrimeVue** — reactive frontend with rich UI components
- **SQLite** — lightweight relational database
- **Redis** — in-memory caching layer
